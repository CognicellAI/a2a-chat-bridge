# User guides

Short, task-focused guides for the person running a self-hosted bridge.

- [Get started](getting-started.md) — install, configure, connect Discord, and
  send your first request.
- [Configuration reference](configuration.md) — settings, auth modes, threads,
  reloads, and state.
- [Operate the bridge](operations.md) — daily commands, health, and recovery.

The bridge connects Discord DMs and configured public threads to Contacts
declared by Agent Card URL. It does not support root-channel messaging, private
threads, Slack, webhooks, or automatic routing.
